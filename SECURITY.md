# Sicherheitslücken in EdDi melden

Bitte melden Sie vermutete Sicherheitslücken **vertraulich** über **Security → Report a vulnerability** in diesem Repository (privates Melden über GitHub) – nicht als öffentliches Issue.

Hilfreich sind: betroffene Version (*Hilfe → Über EdDi*), Schritte zum Nachstellen und, falls möglich, eine Beispieldatei.

Behobene Schwachstellen werden als *Security Advisory* in diesem Repository veröffentlicht; das Update erreicht installierte Versionen automatisch über die Update-Funktion.

Zu jeder Version liegt eine Software-Stückliste (SBOM, CycloneDX 1.6) unter Releases.
